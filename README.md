One original line — a review of planet Earth left by an alien tourist — written
for the [Alien Field Notes: The Two Day Earth Review](https://make.fun/competitions/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000)
competition on [make.fun](https://make.fun).

`main.py` writes the line to `/output/entry.txt`:

> Lovely beaches, clear skies, but every door says PULL and the locals push anyway. I no longer trust this species. Three stars.

The program self-checks the gate before writing: a single line, 1–200 characters,
UTF-8, not only whitespace — and exits non-zero if it fails.
